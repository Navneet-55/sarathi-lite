# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest (main) | ✅ |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, **please do not open a public GitHub issue.**

Instead, report it privately:

- **Email:** kvnavneet@gmail.com
- **Subject:** `[SECURITY] sarathi-lite — <short description>`

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Any suggested fix (optional but appreciated)

You can expect an acknowledgement within **48 hours** and a fix or status update within **7 days**.

## Scope

This is a demo/educational project simulating an RTO portal. It does **not** handle real Aadhaar data, real payments, or any production citizen PII. However, we still take security seriously and will address any valid reports promptly.
