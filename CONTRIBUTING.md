# Contributing to Sarathi Parivahan — Learner's License Portal (Lite)

Thank you for your interest in contributing! This project is maintained by [Navneet](https://github.com/Navneet-55).

## Getting Started

1. **Fork** the repository
2. **Clone** your fork locally:
   ```bash
   git clone https://github.com/your-username/sarathi-lite.git
   cd sarathi-lite
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Start the dev server:**
   ```bash
   npm run dev
   ```

## Development Workflow

- Create a new branch for your feature or fix:
  ```bash
  git checkout -b feature/your-feature-name
  ```
- Make your changes, following the existing code style
- Run the linter before committing:
  ```bash
  npm run lint
  ```
- Commit with a clear message:
  ```bash
  git commit -m "feat: describe your change"
  ```
- Push and open a **Pull Request** against `main`

## Commit Message Format

Use conventional commits:

| Prefix | Use for |
|--------|---------|
| `feat:` | New features |
| `fix:` | Bug fixes |
| `docs:` | Documentation changes |
| `style:` | Formatting, no logic change |
| `refactor:` | Code refactoring |
| `chore:` | Build, config, tooling |

## Code Style

- React functional components with hooks
- Tailwind CSS for styling — no inline styles
- Keep components small and single-purpose
- Follow existing naming conventions
